What is Perle?

Perle is a platform where users complete structured AI tasks through official website quests.

How to Start Quests

  • Visit official website
  • Connect wallet
  • Add small SOL for transaction fees
  • Open Marketplace
  • Select active quest
  • Read instructions carefully
  • Complete tasks accurately
  • Check Earnings / Badge section
