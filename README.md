# Perle Labs Contributor Console

An interactive onboarding console designed to help contributors understand how Perle Labs works, how quests are completed, and how community roles are earned.

This tool simplifies the contributor journey by providing structured guidance inside a clean UI experience.

---

## 🎯 Purpose

Perle Labs has structured quests and role progression, but new contributors may feel confused about:

- Where to start
- How wallet setup works
- How quests are completed
- How roles are assigned
- Where to check official updates

This console solves that by providing a guided walkthrough.

---

## 🧭 What This Covers

### 1. What is Perle Labs
- Structured AI task platform
- On-chain quest execution
- Marketplace-based quest flow

### 2. How to Start Quests
- Connect Solana wallet
- Maintain small SOL for fees
- Select active quests in Marketplace
- Verify completion in Earnings section

### 3. Community Roles (Accurate Flow)

**Perle Explorer**
- Earned by reacting in `#regional-and-perle-roles` channel inside Discord
- Assigned automatically

**Perle Navigator**
- Granted to active and helpful contributors
- Assigned after team review

**Perle Voyager**
- Advanced contributor recognition
- Assigned based on internal evaluation
